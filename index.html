패킷이 지구 반대편까지
가는 길

메시지를 보내면 1초도 안 되어 지구 반대편 친구의 휴대폰이 울린다. 그사이 비트는 전파가 되었다가, 구리선의 전압이 되었다가, 바닷속 유리실을 지나는 빛이 된다. 수십 개의 라우터가 길을 고르고, 데이터센터의 스위치 칩이 초당 수백억 개의 패킷을 나눈다. 신호와 프로토콜에서 유선·무선 통신, 인터넷과 5G, 데이터센터와 클라우드, 그리고 이 모두를 움직이는 통신 반도체까지. 직접 신호를 보내고, 망가뜨리고, 고치며 배우는 네트워크 교과서입니다.

네트워크는 층층이 쌓은 탑이다

각 층은 바로 아래층이 제공하는 기능만 믿고 그 위에 더 편한 기능을 쌓습니다. 맨 아래에는 비트를 전기·빛·전파로 바꾸는 물리와 반도체가 있고, 맨 위에는 우리가 쓰는 앱과 클라우드가 있습니다. 층을 누르면 해당 장으로 갑니다.

이 책을 읽는 방법

수식이나 전문 지식 없이도 따라올 수 있도록 만들었습니다. 각 장은 같은 흐름으로 진행됩니다.

비유택배로 이해하기패킷은 택배 상자, IP 주소는 집 주소, 라우터는 물류 허브, 대역폭은 차선 수, 지연은 이동 시간. 익숙한 물류의 장면으로 먼저 감을 잡습니다.
